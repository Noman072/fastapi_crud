# FastAPI Production Ready

A production-ready FastAPI project with JWT authentication, role-based access, and CRUD operations.

## Features

- **FastAPI**: Modern, fast (high-performance), web framework for building APIs with Python 3.7+ based on standard Python type hints.
- **PostgreSQL**: A powerful, open source object-relational database system.
- **SQLAlchemy ORM**: The Python SQL toolkit and Object Relational Mapper that gives application developers the full power and flexibility of SQL.
- **Alembic**: A lightweight database migration tool for usage with the SQLAlchemy Database Toolkit for Python.
- **Pydantic v2**: Data validation and settings management using Python type annotations.
- **JWT Authentication**: JSON Web Tokens for secure authentication.
- **Role-based Access Control**: Differentiated access for Admin and User roles.
- **CRUD Example**: A complete Create, Read, Update, Delete example for an "Item" model.
- **Modular Project Structure**: Code organized into routers, models, schemas, services, and core modules.
- **Environment-based Settings**: Configuration management using `.env` files and `pydantic-settings`.
- **Centralized Error Handling**: Consistent error responses.
- **Password Hashing**: Secure password storage using `passlib`.
- **Unit Tests**: Basic unit tests using `Pytest`.
- **Docker Compose**: A simple `docker-compose.yml` for running the PostgreSQL database.

## Setup and Installation

1.  **Clone the repository:**

    ```bash
    git clone <repository-url>
    cd Fastapi_crud
    ```

2.  **Create and activate a virtual environment:**

    ```bash
    python -m venv env
    source env/bin/activate  # On Windows use `env\Scripts\activate`
    ```

3.  **Install the dependencies:**

    ```bash
    pip install -r requirements.txt
    ```

4.  **Set up the environment variables:**

    Create a `.env` file in the project root and add the following:

    ```
    DATABASE_URL=postgresql+asyncpg://user:password@localhost/fastapi_db
    JWT_SECRET=myjwtsecret
    ALGORITHM=HS256
    ACCESS_TOKEN_EXPIRE_MINUTES=30
    ```

5.  **Start the PostgreSQL database using Docker:**

    ```bash
    docker-compose up -d
    ```

6.  **Run the database migrations:**

    ```bash
    alembic upgrade head
    ```

7.  **Run the application:**

    ```bash
    uvicorn main:app --reload
    ```

The application will be available at `http://localhost:8000`.
